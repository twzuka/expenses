# Учёт личных расходов

Консольное приложение на Python для учёта личных расходов.

Программа позволяет добавлять категории, записывать расходы, выводить список расходов и считать общую сумму.

## Используемые библиотеки

- `sys` — работа с аргументами командной строки
- `json` — сохранение и загрузка данных

Данные хранятся в файле `data.json`.

## Команды

### Добавить категорию

```bash
python expenses.py add-category <категория>
```

Пример:

```bash
python expenses.py add-category food
```

### Добавить расход

```bash
python expenses.py add <стоимость> <категория> <название>
```

Пример:

```bash
python expenses.py add 99.90 food pizza
```

### Показать расходы

```bash
python expenses.py list
```

Показать расходы по категории:

```bash
python expenses.py list food
```

### Показать сумму расходов

```bash
python expenses.py total
```

Показать сумму по категории:

```bash
python expenses.py total food
```

### Помощь

```bash
python expenses.py help
```

## Обработка ошибок

В программе есть проверка:

- существования категории;
- неизвестной команды;
- количества аргументов;
- корректности стоимости;
- отрицательной стоимости;
- длины названия категории и расхода.

## Пример хранения данных

```json
{
    "food": [
        [
            99.9,
            "pizza"
        ]
    ]
}
```

Категория хранится как ключ словаря, а расходы — как список внутри категории.
